# Ollintep Software &bull; Soluciones Tecnológicas de Vanguardia

Sitio web corporativo y catálogo interactivo de **Ollintep Software**, desarrollado con diseño **Material 3 Expressive (M3E)**, **Tailwind CSS v4** y **View Transitions API**.

🌐 **Sitio Web Oficial:** [https://ollin-tep.com](https://ollin-tep.com)

---

## 🚀 Ecosistema de Productos

### 1. 🏛️ ActaPro
> **Gobernanza y Gestión Digital de Actas**  
> Plataforma integral para secretarías, patronatos y comités de fe pública. Control de quórum, votaciones nominales y certificación criptográfica en 4 etapas.
- **Identidad cromática:** Índigo Real / Tech Purple (`#818cf8`)
- **Acceso:** [Ver Landing Page](https://ollin-tep.com/actapro/)

### 2. 🌾 Agro-Cria Pro
> **Agrotecnología & Precisión Hídrica**  
> Control integral del ecosistema agropecuario con motor determinista de balance hídrico FAO-56 / CROPWAT, ganadería y telemetría IoT LoRaWAN a 915 MHz.
- **Identidad cromática:** Esmeralda Bio / Green Agro (`#10b981`)
- **Acceso:** [Ver Landing Page](https://ollin-tep.com/agrocria/)

### 3. 🔬 Diagmind
> **Auditoría Android & Telemetría en Silicio**  
> Suite forense para dispositivos móviles con Rust y Tauri. Diagnóstico de circuitos en tiempo real (SoC, UFS 4.0, PMIC, DDC-CI AMOLED) y certificación asistida por IA local.
- **Identidad cromática:** Cyber Sky / Azul Eléctrico (`#38bdf8`)
- **Acceso:** [Ver Landing Page](https://ollin-tep.com/diagmind/)

### 4. 🍽️ Ollintep for Restaurants
> **Offline-First POS & Cocina en Tiempo Real**  
> Terminal táctil de punto de venta, comandeo móvil y Kitchen Display System (KDS) sincronizado en red local P2P sin dependencia de internet.
- **Identidad cromática:** Ámbar Gourmet / Warm Gold (`#f59e0b`)
- **Acceso:** [Ver Landing Page](https://ollin-tep.com/restaurant/)

## 🛠️ Tecnologías y Arquitectura

- **CSS & Diseño:** Tailwind CSS v4 + Material 3 Expressive (superficies tonales, sin bordes de color duros, elevación suave).
- **Animaciones & Navegación:** View Transitions API nativa, CSS Keyframes orbitales, Logo Marquee continuo y orbes líquidos ambientales.
- **Compilación:** `@tailwindcss/cli v4.3.3` minificado.
- **SEO & Accesibilidad:** Schema.org JSON-LD, Open Graph, Sitemap XML y reducción de movimiento (`prefers-reduced-motion`).

```bash
# Compilar estilos CSS:
npm run build:css
```
